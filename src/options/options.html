常规

控制汉化的全局行为。修改会立即保存，并通过 chrome.storage.onChanged 同步到所有 AI Studio 标签页。

启用汉化

总开关。关闭后页面保持英文原文，扩展不再修改任何文本。

强制英文界面

通过 declarativeNetRequest 让 AI Studio 以英文渲染，保证词典命中一致；修改后需刷新页面。

译文高亮

给译文加浅紫色底纹，便于逐条校对；日常使用建议关闭。

悬停看原文

鼠标悬停译文时，用 tooltip 显示对应的英文原文。

翻译属性文案

同时处理 placeholder / aria-label / title / alt 等属性中的界面文案。

收集未汉化文案

把未命中词典的英文 UI 文案记录到本地，方便在「未汉化收集」里补充词条。

恢复默认设置

不影响词典

把以上六个开关、排除规则与动态规则恢复为默认值；自定义词典与未汉化记录会保留。

    动态规则（进阶）

    用正则把带变量的界面文案映射为中文模板，例如 Show 12 more → 再显示 12 项。

    正则来自本地存储，仅作用于文本，不会执行代码

    规则只通过 String.replace 处理文本节点；不会 eval、不会注入 HTML、不会发起网络请求。

    汉

    Google AI Studio 汉化 v1.0.0

    用「词典精确匹配 + 正则动态规则」把 AI Studio 界面确定性汉化，绝不翻译模型输出、代码或用户提示词。

    —内置词条 0自定义词条 Alt+Shift+H开关汉化

    功能清单

    • 词典精确匹配 + 正则动态规则，确定性汉化
    • 跳过代码块、编辑器、聊天富文本与图标连字
    • 支持 placeholder / aria-label / title / alt
    • 自定义词条优先级最高，可覆盖内置词条
    • 收集未汉化候选，一键复制补充词条
    • 译文高亮、悬停看原文，便于校对

    使用方式

    1. 在 chrome://extensions 开启开发者模式，加载本项目根目录。
    2. 打开 https://aistudio.google.com/，页面自动汉化。
    3. 点击工具栏图标查看本次翻译统计，或进入本页调整设置。

    快捷键

    Alt+Shift+H开关当前页汉化

    若与其他扩展冲突，可在 chrome://extensions/shortcuts 中修改。

    术语表

    CONTRACT §6

    全项目统一译法，自定义词条也应遵循，避免同一术语出现多种译法。

    已知限制

    • 不翻译模型输出、代码、用户输入与文件内容（这是特性，不是缺陷）。
    • AI Studio 前端更新后可能出现新的英文文案，需要补充词典或动态规则。
    • 若页面已加载为中文，部分词典键无法命中，建议开启「强制英文界面」并刷新。
    • 内置词条由翻译引擎提供，本页仅能展示后台给出的只读快照。
