## 📦 安装

1. 下载本 Release 的 `google-ai-studio-zh-1.1.0.zip` 并解压（或使用源码目录）。
2. 打开 `chrome://extensions`（Edge 为 `edge://extensions`），开启「开发者模式」。
3. 「加载已解压的扩展程序」→ 选择包含 `manifest.json` 的目录。
4. 打开 https://aistudio.google.com/ 自动生效；`Alt+Shift+H` 一键开关。

已装过 v1.0.0 的用户：在扩展管理页点「重新加载」即可升级（自定义词条不受影响）。

## ⚠️ 已知限制

- 模型卡后台描述、示例提示词等 Google 动态内容保持英文（设计如此，可在设置页自行补词）。
- 本扩展为第三方开源项目，与 Google 无关；隐私：零网络请求，数据仅存本地。
