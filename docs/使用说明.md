## 1. 产品特色：为什么选择本插件？

普通浏览器网页翻译（如 Chrome 全页翻译）在面对 Google AI Studio 这种高度动态的 AI 控制台时，常常出现：
- **乱译**：把变量名、模型参数（如 Temperature 变成“体温”）、Python 代码全部翻译得面目全非。
- **页面崩溃**：翻译破坏了页面的 DOM 节点，导致点击“Run”无反应、提示词输入框错位、聊天气泡丢失。
- **卡顿延迟**：全页扫描并请求外部机器翻译接口，网络延迟高，界面闪烁严重。

**本插件的独家优势**：
1. **纯净离线**：内置全量专业词典，毫秒级本地匹配，不耗费任何网络流量。
2. **三不翻译红线**：**不翻译**用户提示词（Prompt）、**不翻译** AI 模型生成的对话回复、**不翻译**代码块。只汉化按钮、菜单、参数滑块与帮助说明。
3. **零崩溃风险**：深度适配 Angular / Polymer 单页渲染机制，不破坏界面原生事件与数据绑定。

## 3. 图文安装步骤（保姆级手把手）

### 方式一：加载已解压的文件夹（推荐，随时体验最新版）

#### 第一步：准备插件目录
- 将插件项目文件夹 `google-ai-studio-zh` 放置在一个固定的磁盘目录下（例如：`D:\ChromeExtensions\google-ai-studio-zh`）。
- **提示**：安装后请勿随意移动或删除此文件夹，否则扩展会失效。

#### 第二步：打开浏览器扩展程序管理页面
- 在 Chrome 浏览器地址栏中输入：`chrome://extensions/` 并按回车。
- （若是 Edge 浏览器，请输入：`edge://extensions/`）。

#### 第三步：开启“开发者模式”
- 观察页面右上角，找到【开发者模式】（Developer Mode）开关，将其**点击开启**（滑块变为蓝色或激活状态）。
- 开启后，页面左上方将出现三个新按钮：【加载已解压的扩展程序】、【打包扩展程序】、【更新】。

```
[浏览器顶部导航栏]
-------------------------------------------------------------------------
 扩展程序 (chrome://extensions)               [搜索扩展]    [开发者模式: 开]
-------------------------------------------------------------------------
 [ 📁 加载已解压的扩展程序 ]   [ 📦 打包扩展程序 ]   [ 🔄 更新 ]
-------------------------------------------------------------------------
```

#### 第四步：选择并加载文件夹
- 点击【加载已解压的扩展程序】按钮。
- 在弹出的文件选择器中，定位并选中 `google-ai-studio-zh` 根目录（即包含 `manifest.json` 的文件夹），点击【选择文件夹】。
- 此时页面卡片列表中将出现 **Google AI Studio 汉化助手** 卡片，并显示版本号与“中”字图标。

#### 第五步：将插件图标固定在浏览器工具栏
- 点击浏览器地址栏右侧的“拼图”图标（扩展程序总按钮）。
- 找到“Google AI Studio 汉化助手”，点击右侧的“图钉”图标（📌）。
- 紫蓝渐变、中间带有白色“中”字的漂亮方块图标即可常驻显示在浏览器右上角。

---

### 方式二：通过打包文件安装 (.zip)
1. 下载发布页面提供的 `google-ai-studio-zh-1.0.0.zip`。
2. 解压到本地任意目录（例如解压到当前文件夹）。
3. 按照“方式一”的步骤加载该解压后的文件夹即可。

## 6. 工具栏弹窗 (Popup) 核心操作指南

在 AI Studio 页面中，点击右上角的插件图标，将展开精美的快捷悬浮窗面板：

```
+-------------------------------------------------------+
|  [中] Google AI Studio 汉化助手               v1.0.0  |
+-------------------------------------------------------+
|                                                       |
|  [ 状态卡片 ]                                         |
|  ● 当前页面: 已启用汉化                               |
|  本页已翻译 UI 节点: 48 项                            |
|                                                       |
|  ---------------------------------------------------  |
|  [主要开关]                                           |
|  [√] 开启汉化翻译                [ 开关控件 ]         |
|  [√] 强制英文底本 (DNR)          [ 保证命中稳定 ]     |
|  [ ] 译文底纹高亮                [ 辅助校对定位 ]     |
|  [ ] 鼠标悬停显示英文            [ 查看原文Tooltip ]  |
|  [√] 翻译属性文案                [ placeholder/title] |
|                                                       |
|  ---------------------------------------------------  |
|  [快捷操作]                                           |
|  [ 🔄 重新翻译本页 ]           [ ↩ 还原英文显示 ]     |
|                                                       |
|  ---------------------------------------------------  |
|  [ ⚙ 打开高级设置页 ]                                 |
+-------------------------------------------------------+
```

### 开关功能详述：
- **开启汉化翻译**：插件总开关。关闭后立即恢复纯英文原生界面，扩展停止改写任何文本。
- **强制英文底本 (DNR)**：打开后扩展会把 AI Studio 地址中的 `hl` 参数统一改写为 `en`，让服务器始终返回标准英文界面，避免中英混排导致词典匹配失效（强烈建议常开，修改后刷新一次页面生效）。
- **译文底纹高亮**：开启后，所有被汉化的文案会带一条淡紫色下划线底纹（不改变任何排版尺寸），方便您一眼区分哪些文案已被汉化。
- **鼠标悬停显示英文**：开启后，鼠标悬停在汉化后的按钮或文本上时，会浮现一个微型黑色气泡，显示其对应的英文原文（如鼠标悬停在“对话实验室”上方浮现 `Playground`）。
- **翻译属性文案**：不仅汉化可见文本，连同输入框内的灰色占位符提示（placeholder）、鼠标浮动说明（title）和无障碍提示（aria-label）一起汉化。
- **重新翻译本页**：当页面发生深层局部刷新或切换 Tab 时，一键触发全页面重绘扫描。
- **还原英文显示**：清除本页译文并关闭总开关，随时用总开关恢复中文。

## 7. 高级设置页 (Options) 七大分区详解

点击 Popup 下方的【打开高级设置页】，或在扩展管理页点击【选项】，即可进入全功能配置工作台。

### 分区 1：常规
- 六个开关：启用汉化 / 强制英文界面 / 译文高亮 / 悬停看原文 / 翻译属性文案 / 收集未汉化文案，每个开关下面都有一行用途说明。
- 「恢复默认设置」只重置开关、排除规则与动态规则，不会删除你的自定义词典和未汉化记录。

### 分区 2：词典管理
- 顶部显示内置词条数（当前版本约 850 条去重词条）、自定义词条数与当前筛选数量。
- 支持按英文或中文实时搜索，按「全部 / 内置 / 自定义」过滤，分页浏览。
- 新增词条：填英文原文 + 中文译文，保存即写入 `aiz.customDict`，优先级最高。
- 行内编辑：点「编辑」直接在表格里改，Enter 保存、Esc 取消。
- 导出 / 导入词典 JSON：导入时若与现有词条冲突，可选择「导入优先」或「保留现有」。

### 分区 3：排除规则
- 内置规则以标签形式展示（图标字体、代码块、可编辑区、聊天记录等），只读不可删。
- 可追加自定义 CSS 选择器，输入时实时预览在当前设置页命中的元素数量。

### 分区 4：动态规则（进阶）
- 展示内置的 78 条动态正则（Token 计数、相对时间、账号标签、模型定价、删除确认等）。
- 可添加自己的正则规则（正则 / 替换模板 / 说明），并提供实时测试框；规则只作用于文本，不会执行代码。

### 分区 5：未汉化收集
- 列出自动收集到的未命中英文文案与出现次数，可搜索、勾选、复制为 JSON、下载 txt 或清空。

### 分区 6：数据与备份
- 导出全部配置（设置 + 自定义词典 + 未汉化记录）为 JSON；导入时会校验格式；「重置全部数据」需要输入 `RESET` 二次确认。

### 分区 7：关于
- 查看当前安装的版本号（1.0.0）、快捷键、功能清单、已知限制与更新日志。

## 8. 常见问题快速排查 (FAQ)

### Q1: 安装后进入 Google AI Studio，为什么部分词条还是英文？
- **原因 1**：Google 刚发布了新版或灰度测试了全新 UI 文案，本地词典尚在跟进补充中。
- **原因 2**：页面采用长列表滚动懒加载，刚滚动出来的元素等待下一次微任务渲染。
- **解决办法**：按快捷键 `Alt + Shift + H` 触发一次即时重新翻译；或者在【自定义词典】中将该英文词条及译文添加进去，立即生效！

### Q2: 为什么我的代码块或模型回答里有时出现中文？
- **解答**：这属于 AI 模型自身遵循您的中文 Prompt 作出的中文回答。本插件绝对不会篡改任何模型生成数据或代码逻辑。

### Q3: 为什么快捷键 `Alt + Shift + H` 没有反应？
- **解答**：请检查是否有其他系统级软件（如显卡驱动控制台、截图工具、输入法）占用了该快捷键。您可以在浏览器输入 `chrome://extensions/shortcuts` 查看或重新绑定新的快捷键。

### Q4: 提示“无法连接到当前页面”或扩展图标呈灰色？
- **解答**：本插件严格限定只在 `https://aistudio.google.com/*` 域名下激活运行。在浏览器设置页、空白页或其他无关网站上属于休眠状态，此为正常安全行为。

### Q5: 遇到问题如何反馈？
- **解答**：欢迎访问项目开源仓库提交 Issue，或使用 Options 页面中的“导出未匹配词条”功能将数据反馈给维护团队。
