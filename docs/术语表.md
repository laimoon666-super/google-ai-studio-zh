## 一、翻译原则与质量红线

1. **确定性优于文学性**：UI 文案以精准传达功能意图为第一准则，按钮、标签类优先保持 ≤8 个汉字，简洁凝练。
2. **严格保护代码与模型数据**：品牌名（Google、Gemini、AI Studio、Imagen、Veo）、专有名词（Token、JSON Schema、REST API、SDK）、模型名称（`gemini-2.5-pro`、`gemini-2.5-flash`）、代码块内容、用户 Prompt 原文与模型输出一律严禁汉化。
3. **保留官方口径**：与 Google Cloud / Google Developers 中文官方文档保持同口径（例如：“Grounding”译为“接地”，“System instructions”译为“系统指令”）。
4. **统一标点与空格**：中文与英文单词之间自然排版，半角冒号与中文全角冒号视上下文保持与原 UI 一致，无额外杂质字符。
