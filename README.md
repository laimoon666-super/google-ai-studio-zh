## 一、项目简介

**Google AI Studio 汉化助手** 是一款专为 `https://aistudio.google.com/*` 深度定制的纯前端本地化扩展程序。

### 为什么不使用浏览器自带的“全页机器翻译”？
许多开发者在使用 Chrome 自带全页翻译时深受困扰：
- **致命破坏**：机器翻译会强行翻译代码块（如 Python 变量被翻译）、篡改用户 Prompt、破坏 Angular 数据绑定，导致点击“Run”无响应或输入框光标错位。
- **术语灾难**：将 `Temperature` 译为“体温”、`Grounding` 译为“接地线”、`Thinking budget` 译为“打折预算”，严重误导参数调优。
- **网络延迟**：全页翻译需经过云端机器翻译接口，页面严重闪烁、延迟高。

**我们的方案**：
坚持**确定性精确匹配 + 动态模板规则**路线。基于人工专业勘察建立的大规模词典库，在本地 DOM 层进行精准汉化。**只翻译 UI 控件与提示文案，严守底线，绝对不触碰用户的 Prompt 原文、模型回复与示例代码！**

## 二、核心功能特色 (12 大亮点)

1. **纯本地离线词典匹配**：内置全量官方口径词汇分卷，毫秒级瞬时替换，无需访问任何外部翻译 API，无网络依赖，极致快速。
2. **三不触碰原则（严格数据隔离）**：坚守原则：**不翻译**用户输入的 Prompt、**不翻译**模型流式生成的回复正文、**不翻译**代码块（Code Blocks），确保研发业务严谨性。
3. **权威专业术语统一**：全面对照 Google Cloud 与 Google Developers 官方中文口径（如“系统指令”、“已接地”、“结构化输出”、“思考预算”），杜绝生搬硬套。
4. **动态模板与正则规则引擎**：内置专用规则处理器，覆盖带数字、时间、状态的动态文本（如“1,024 个 Token”、“更新于 5 分钟前”、“显示 10 个项目中的第 1 个”）。
5. **深入属性层级汉化 (Attributes)**：不仅汉化可见文本，连同输入框占位符（`placeholder`）、悬停提示（`title`）、无障碍标签（`aria-label`）全面汉化，消除英文死角。
6. **网络层强制英文底本 (DNR 协同)**：通过 `declarativeNetRequest` 把 AI Studio 请求地址中的 `hl` 查询参数改写为 `en`，让服务器始终返回标准英文 UI，避免中英混排导致词典命中不稳定（该能力可在弹窗中一键关闭）。
7. **译文底纹高亮校对模式**：支持一键开启柔和半透明紫色底纹，直观标识哪些区域已汉化，方便词典校对与调试。
8. **悬停查阅英文原文 (Tooltip)**：开启后鼠标悬停在汉化文本上方即弹出微型气泡展示英文原文，中英随时对照，降低上手认知成本。
9. **用户级自定义词典中心**：内置可视化自定义词库编辑器，用户可根据自身偏好随时覆盖既有译法或新增专属词条，优先级高于内置词典。
10. **未命中英文文案智能收集箱**：在您浏览时自动捕捉页面上新增的未翻译 UI 词条并统计频次，支持一键加入个人词典或导出反馈。
11. **单页应用（SPA）防抖与防护**：深度适配 Angular 数据渲染机制，用 `seen` / `processed` 双集合做幂等防护、`applied` WeakMap 识别自身写入，并以「每 10ms 最多 400 个节点」的节流队列增量处理，彻底杜绝死循环与崩溃。
12. **极简优雅原生设计系统**：弹窗与设置页采用 Material 3 风格纯原生构建（紫蓝渐变点缀、深浅色自适应、键盘可操作），零第三方框架，内存占用极低。

## 三、安装指南 (Chrome / Edge)

### 3.1 开发者模式安装（推荐，随源码实时体验）

1. **下载或克隆源码**：将本扩展仓库拉取或解压到本地固定磁盘目录（例如：`D:\extensions\google-ai-studio-zh`）。
2. **打开扩展程序管理页面**：
   - **Google Chrome**：在地址栏输入 `chrome://extensions/` 并按回车。
   - **Microsoft Edge**：在地址栏输入 `edge://extensions/` 并按回车。
3. **开启“开发者模式”**：在页面右上角找到【开发者模式】（Developer Mode）开关，将其开启。
4. **加载扩展程序**：
   - 点击页面左上角出现的【加载已解压的扩展程序】按钮。
   - 在弹出的文件夹选择框中，选择包含 `manifest.json` 的 `google-ai-studio-zh` 根目录。
5. **固定图标**：点击浏览器右上角拼图形状的扩展图标，将“Google AI Studio 汉化助手”固定（Pin）到工具栏。

### 3.2 离线 Zip 包安装

1. 从项目 Release 页面下载打包好的 `google-ai-studio-zh-1.0.0.zip`。
2. 解压到一个固定文件夹中。
3. 按照上述【3.1】中的步骤，在“开发者模式”下点击“加载已解压的扩展程序”并选择解压后的文件夹即可。

### 2. 工具栏弹窗 (Popup) 功能详解

在 `https://aistudio.google.com/` 页面点击浏览器右上角插件图标，即可打开悬浮控制卡片：

- **状态卡片**：实时展示当前网页汉化生效状态及本页已翻译的 UI 节点数量。
- **主要开关**：
  - **开启汉化翻译**：总开关，关闭后即刻恢复纯英文界面。
  - **强制英文底本**：确保 Google 服务器返回标准英文 UI 模板，保障词典 100% 稳定命中。
  - **译文底纹高亮**：为已汉化节点添加浅色标记，方便对照。
  - **悬停显示英文**：鼠标悬停出现原生 Tooltip 显示对应英文原词。
  - **翻译属性文案**：同步汉化 `placeholder` / `aria-label` / `title` 等隐藏属性。
- **快捷动作**：
  - **重新翻译本页**：当切换不同选项卡或遇到复杂动态折叠面板时，一键触发全量复核。
  - **还原英文显示**：清除本页汉化标记与中文内容，无缝对照英文原貌。
- **前往设置**：一键进入完整选项控制台。

### 3. 高级选项页 (Options) 七大分区详解

点击 Popup 下方的【打开设置页】可进入全屏配置面板（支持独立书签保存）：

1. **常规**：总开关、强制英文界面、译文高亮、悬停看原文、翻译属性文案、收集未汉化文案六个开关，每个都带一行用途说明；底部可一键恢复默认设置（不影响自定义词典与未汉化记录）。
2. **词典管理**：展示内置词条总数与自定义条数，支持按英文/中文实时搜索、按"全部/内置/自定义"过滤、分页浏览；可新增词条、行内编辑、删除、导出/导入词典 JSON（冲突时可选择导入优先或保留现有）。
3. **排除规则**：内置跳过规则以 chips 只读展示（图标连字、代码、可编辑区、聊天内容等），并支持追加自定义 CSS 选择器；输入选择器可实时预览在当前页面命中的元素数量。
4. **动态规则（进阶）**：内置 70+ 条带变量的锚定正则（如 Token 计数、相对时间、账号标签）只读展示；用户可新增自己的正则规则，并提供实时测试框与"仅作用于文本、不执行代码"的安全提示。
5. **未汉化收集**：列出自动收集到的未命中英文文案、出现次数与来源页面，支持搜索、勾选、复制为 JSON、下载 txt 与清空。
6. **数据与备份**：一键导出全部配置（设置 + 自定义词典 + 未汉化记录）为 JSON、导入配置校验、危险操作"重置全部数据"需输入 `RESET` 二次确认。
7. **关于**：版本号、快捷键、功能清单、已知限制与更新日志。

## 五、工作原理与技术架构

```
[ 用户访问 aistudio.google.com ]
                │
                ▼
[ declarativeNetRequest 介入 ] ──> 把 URL 的 hl 参数改写为 en，获取标准英文 DOM
                │
                ▼
[ Document Idle / Content Script 注入 ]
                │
        ┌───────┴────────────────────────┐
        ▼                                ▼
[ 加载内置词库分卷 ]              [ 加载动态正则模板库 ]
( _common / playground /          ( patterns.js 提取变量
  build / manage / custom )         如 token 计数、时间等 )
        │                                │
        └───────────────┬────────────────┘
                        ▼
            [ Core Engine 扫描与过滤 ]
             - 跳过 Material Symbols 连字图标
             - 跳过 user prompt / model response / code
                        │
                        ▼
            [ 执行 DOM 替换与属性赋值 ]
             - textContent -> 简体中文
             - placeholder / title / aria-label -> 简体中文
             - 打上 data-aiz-zh / data-aiz-orig 标记（保留原文，可一键还原）
                        │
                        ▼
        [ MutationObserver 异步微任务防抖监听 ]
    ( 捕获 Angular 局部路由跳转与抽屉展开，增量汉化，绝不循环 )
```

## 七、已知限制与兼容性维护

1. **SPA 懒加载延迟**：对于数千行超长历史记录或深层抽屉弹窗，由于 Angular 采用虚拟滚动（Virtual Scroll），新滑入可视区域的元素可能存在毫秒级的微小延迟，随后会自动瞬时完成汉化。
2. **Material Symbols 保护**：Google 界面将部分图标作为文本渲染（例如 `close`、`search`）。本扩展严格对这些标签进行跳过防护；极少数非标准标签的图标若被误汉化，可通过 Options 中的黑名单选择器将其加入排除。
3. **Google 界面改版应对机制**：若 Google 调整了 HTML 结构或发布了新功能：
   - 用户可直接在【自定义词典】中添加新词条，无需等待新版本发布。
   - 开发者可使用 `docs/维护指南.md` 中的勘察脚本一键 Dump 页面数据，补入对应分卷词典并运行 `scripts/pack.ps1` 发版。

## 八、隐私安全声明与权限逐条解释

本扩展遵循严格的隐私保护与最小权限原则，代码 100% 透明开源。

### 1. 零网络请求
- 扩展内部**没有任何**向外部服务器发送请求的代码（无 Google Analytics、无 Sentry、无任何第三方统计脚本）。
- 绝不收集、记录、上传用户的 Google 账号信息、API 密钥、Prompt 内容或对话结果。

### 2. 权限使用说明 (对照 manifest.json)
| 申请权限 | 权限类型 | 实际用途与安全保证 |
| :--- | :--- | :--- |
| `storage` | permissions | 仅用于将用户的开关偏好、自定义词典和未命中词条持久化存储在**浏览器本地**（`chrome.storage.local`），换机或清除浏览器数据前可自行导出。 |
| `declarativeNetRequestWithHostAccess` | permissions | 仅针对 `https://aistudio.google.com/*`，把页面地址中的 `hl` 查询参数改写为 `en`，保证服务器返回统一的英文 UI 模板；不读取、不上传任何请求体或响应内容。 |
| `https://aistudio.google.com/*` | host_permissions | 严格将内容脚本（Content Script）的生效范围限定在 Google AI Studio 域名下，绝不越权触碰其他任何网页。 |

## 九、常见问题解答 (FAQ)

### Q1: 扩展安全吗？会不会泄露我的 API Key 或 Prompt？
**答：绝对安全！** 本扩展采用 100% 离线纯前端架构，所有词典与引擎均内置在本地扩展包内。我们严守安全底线，对 Prompt 输入框与 API Key 显示区域做了硬隔离；且扩展本身没有申请任何外部网络连接权限，物理上无法向任何外部服务器发送数据。

### Q2: 为什么我的代码块（Python/curl/JS）没有被翻译？
**答：这是刻意设计的核心特性！** 代码中的函数名、变量名（如 `genai.configure(api_key=...)`）一旦被翻译会导致代码无法正常运行。因此代码块（`pre`、`code`、`kbd`、`samp`、`.hljs`）均在绝对保护黑名单中，保持纯英文原样。

### Q3: 为什么部分模型回复里依然是英文？
**答：模型回复内容属于“非 UI 动态数据”，受严格保护！** 如果您希望模型用中文回复，只需在 Prompt 中使用中文提问，或在【系统指令】（System instructions）中添加“请始终使用中文回复”。本插件只汉化操作界面，不越权篡改 AI 生成结果。

### Q4: 提示词输入框的灰色占位文字为什么有时候没有翻译？
**答：** 占位文字属于"属性翻译"（`placeholder`），请检查设置页【常规】里的「翻译属性文案」开关是否开启；此外，输入框里已经输入的内容属于用户数据，引擎会完整保护、不做任何改写。若刚切换过页面，点一下 popup 里的【重新翻译】即可补齐。

### Q5: 快捷键 `Alt + Shift + H` 无法触发怎么办？
**答：** 通常是因为该快捷键被操作系统其他软件（如显卡控制面板、通讯工具快捷键、输入法快捷键）全局占用。请在 Chrome 地址栏访问 `chrome://extensions/shortcuts`，为“Google AI Studio 汉化助手”设置一组您习惯的专属快捷键。

### Q6: 是否支持繁体中文或其他语言？
**答：** 当前版本原生词典专注于符合中国大陆开发者习惯的规范简体中文。由于词典架构高度模块化，未来可轻松扩展繁体中文（zh-TW / zh-HK）词库。

### Q7: 我自定义的词典保存在哪里？重装系统会丢失吗？
**答：** 自定义词典存储在您浏览器的本地存储库（`chrome.storage.local`）中。重装系统或更换电脑前，强烈建议在【设置页】->【备份与迁移】分区点击【导出配置】，将 `.json` 备份文件妥善保存，在新环境中一键导入即可无缝恢复。

### Q8: Google AI Studio 界面改版导致部分词条失效，如何解决？
**答：** 您可以先通过 Popup 打开【设置页】，在【未命中词条收集箱】中查看新出现的词条，并一键录入【自定义词典】应急；同时欢迎在 GitHub 提交 Issue 或 PR，团队会在勘察后快速更新内置分卷词典并发布新版。

### Q9: 为什么页面的某些小图标变成了方块或文字？
**答：** 本插件通过多层选择器与字体特征检测排除了 Google Material Symbols 图标连字。如遇到新改版造成的偶发异常，可按 `Alt + Shift + H` 重译，或在设置页提交反馈。
